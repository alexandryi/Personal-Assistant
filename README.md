# 📒 Personal Assistant — вебзастосунок на Django

## 🧩 Опис проєкту

**Personal Assistant** — це вебзастосунок для керування особистою інформацією, створений за допомогою Django.

Система дозволяє користувачам:

- 📇 зберігати контакти
- 📝 створювати нотатки
- 📁 завантажувати файли
- 📰 переглядати ігрові новини
- 🔐 використовувати персональний акаунт із авторизацією

Кожен користувач має доступ лише до власних даних.

---

# 🚀 Основні можливості

## 🔐 Авторизація та автентифікація

Реалізовано:

- 👤 Реєстрацію користувача
- 🔑 Вхід у систему
- 🚪 Вихід із системи
- 🔄 Відновлення пароля

Після входу користувач автоматично переходить на сторінку контактів.

# 📇 Робота з контактами

## CRUD-функціонал

### ➕ Створення контакту

Користувач може додати:

- ім’я
- email
- номер телефону
- адресу
- дату народження

---

### ✏️ Редагування контакту

Можна змінювати інформацію про контакт.

---

### 🗑️ Видалення контакту

Контакти можна видаляти із книги контактів.

---

### 🔍 Пошук контактів

Пошук реалізований за ім’ям контакту.

---

### 🎂 Пошук днів народження

Користувач може вказати кількість днів, після чого система покаже контакти, у яких день народження буде протягом цього періоду.

#### Приклади:

- `7` → дні народження протягом 7 днів
- `30` → протягом 30 днів
- `365` → усі найближчі дні народження

---

### ✅ Валідація даних

#### Телефон

Телефон повинен:

# 🗂️ Структура проєкту

```text
Project-Python-Web/
│
├── config/                  # Налаштування Django
│
├── apps/
│   ├── contacts/            # Модуль контактів
│   ├── notes/               # Модуль нотаток
│   ├── files/               # Модуль файлів
│   ├── news/                # Модуль новин
│   └── users/               # Авторизація користувачів
│
├── media/                   # Завантажені файли
├── static/                  # CSS / JS / Bootstrap
├── templates/               # Базові HTML-шаблони
│
├── db.sqlite3               # SQLite база даних
├── manage.py                # Django manager
├── requirements.txt         # Залежності
└── README.md                # Документація
```

# 🛠️ Встановлення та запуск

## 1️⃣ Клонування репозиторію

```bash
git clone <посилання_на_репозиторій>
```

---

## 2️⃣ Перехід у папку проєкту

```bash
cd Project-Python-Web
```

---

## 3️⃣ Створення віртуального середовища

```bash
python -m venv venv
```

---

## 4️⃣ Активація середовища

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## 5️⃣ Встановлення залежностей

```bash
pip install -r requirements.txt
```

---

## 6️⃣ Міграції бази даних

```bash
python manage.py migrate
```

---

## 7️⃣ Запуск сервера

```bash
python manage.py runserver
```
